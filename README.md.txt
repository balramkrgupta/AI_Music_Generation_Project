# AI Music Generation using LSTM

## Project Description
This project generates new music using Artificial Intelligence. It uses MIDI music files as input, preprocesses them using the Music21 library, trains an LSTM (Long Short-Term Memory) neural network with TensorFlow, and generates new music that is saved as a MIDI file.

## Features
- Read MIDI music files
- Extract musical notes
- Preprocess note sequences
- Train an LSTM neural network
- Generate new music
- Save generated music as a MIDI file

## Technologies Used
- Python
- Google Colab
- TensorFlow
- Music21
- NumPy

## Project Files
- AI_Music_Generation.ipynb
- music_model.keras
- generated_music.mid

## Output
The trained AI model generates a new MIDI music file named `generated_music.mid`.
